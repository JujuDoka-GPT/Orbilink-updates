# Orbilink

Fichiers de distribution des mises à jour Android d’Orbilink.

Installer les nouvelles versions en mise à jour, en conservant l’application existante. Les bulles, placements et photos restent dans le stockage privé du téléphone. Ce dépôt contient uniquement des fichiers de distribution, aucune donnée personnelle des utilisateurs et aucune clé de signature.

Dans Orbilink : Réglages et sauvegarde → Mises à jour → Rechercher.
